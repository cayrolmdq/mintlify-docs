Gastuki es una plataforma para **gestionar gastos personales por WhatsApp** y un
**programa de fidelización y analítica para comercios**. Esta documentación
explica **qué hace** cada feature y **cómo funciona** desde el punto de vista del
usuario, no cómo está implementada internamente.

Está pensada para que cualquier persona (producto, soporte, comercios,
integradores) entienda los requerimientos funcionales del producto.

## ¿Qué es Gastuki?

Gastuki tiene tres audiencias y tres superficies de uso:

| Audiencia | Quién es | Cómo lo usa |
|-----------|----------|-------------|
| **Clientes** (usuarios finales) | Personas que quieren controlar sus gastos | WhatsApp (texto, voz, imagen) + web app |
| **Comercios** (merchants) | Negocios que quieren fidelizar clientes | Panel web / API `/merchant/*` |
| **Agentes de IA** (MCP) | Comercios y usuarios que consultan sus datos desde Claude u otro cliente | Servidor MCP por OAuth |

El corazón del producto es el **asistente de WhatsApp**: el cliente le escribe en
lenguaje natural ("gasté $500 en pan") y la IA extrae, categoriza y registra la
operación. Sobre esa base se construyen presupuestos, listas de compras, cupones,
sellos de fidelidad, ruleta de premios, campañas y reportes.

## Conceptos clave (glosario rápido)

- **Cliente / Usuario final**: persona identificada por su número de teléfono (WhatsApp).
- **Comercio / Merchant**: negocio dado de alta con datos legales (CUIT).
- **Perfil (profile)**: registro del usuario final dentro de Gastuki.
- **Gasto (expense)**: salida de dinero registrada por el usuario.
- **Ingreso (income)**: entrada de dinero registrada por el usuario.
- **Sello (stamp)**: punto de fidelidad que un comercio otorga por compra.
- **Cupón (coupon)**: código de descuento o beneficio canjeable.
- **Happy Moment / Ruleta**: juego de premios que se ofrece tras una compra.
- **Cupón de recupero**: cupón que se asigna a clientes inactivos para reactivarlos.
- **MCP**: protocolo que permite a un agente de IA leer datos de Gastuki vía OAuth.

<Note>
  **Zona horaria:** Gastuki opera con calendario de Argentina (ART, UTC−3). Los
  totales mensuales y los rangos de período se calculan respetando esa zona.
</Note>

## Cómo está organizada la plataforma (alto nivel)

```
Cliente final ──WhatsApp/Web──▶ API Gastuki ──▶ Comercio (panel/API)
                                    │
                                    └── Servidor MCP ──OAuth──▶ Agentes de IA (Claude, etc.)
```

El backend sigue **Clean Architecture + DDD**. Cada feature de negocio vive en su
propio módulo. Esta documentación describe el **comportamiento funcional**, no el
código.
